📱 Android Interview Preparation (With Answers)

🧠 1. OOPs with Answers

1. What are the 4 pillars of OOP?
Encapsulation, Abstraction, Inheritance, Polymorphism.
2. Encapsulation vs Abstraction?
Encapsulation = hiding data (data security). Abstraction = hiding implementation (show only essential features).
3. Inheritance vs Composition?
Inheritance = IS-A relationship. Composition = HAS-A relationship. Composition is more flexible.
4. What is polymorphism?
Ability of one object to take multiple forms (method overloading & overriding).
5. Overloading vs Overriding?
Overloading = same method name, different parameters. Overriding = child class changes parent method.
6. Interface vs Abstract class?
Interface = full abstraction. Abstract class = partial implementation allowed.
7. Why no multiple inheritance in classes?
To avoid ambiguity (diamond problem).

🏗️ 2. SOLID Principles (With Answers)

S - Single Responsibility?
One class should have only one reason to change.
O - Open/Closed?
Code should be open for extension but closed for modification.
L - Liskov Substitution?
Child class should replace parent class without breaking code.
I - Interface Segregation?
Prefer multiple small interfaces instead of one big interface.
D - Dependency Inversion?
Depend on abstractions, not concrete classes (used in DI frameworks like Hilt).

📱 3. Android LLD (With Answers)

Q: Design WhatsApp?
Use MVVM + Repository + WebSocket.
Entities: User, Chat, Message.
Local DB: Room
Real-time: Firebase/WebSocket
Q: Design Instagram feed?
Use pagination + caching + API layer + ViewModel.
Feed loads via repository and updates UI via LiveData/Flow.
Q: Why Repository pattern?
It separates data sources (API, DB) and keeps ViewModel clean.
Q: Why MVVM in Android?
Separates UI, business logic, and data handling → better testability and maintainability.
Q: Where SOLID is used in Android?
ViewModel (SRP), Repository (DIP), Use small interfaces (ISP), extend features without modifying old code (OCP).

💻 4. Coding Questions with Answers

1. Reverse String
Use two pointers or built-in reverse() in Kotlin.
2. Two Sum
Use HashMap → store number and index → check target - num.
3. LRU Cache
Use HashMap + Doubly Linked List for O(1) access and eviction.
4. Valid Parentheses
Use Stack → push opening brackets, match closing brackets.
5. Longest substring without repeat
Use Sliding Window + HashSet/Map.
6. Find missing number
Use formula n(n+1)/2 - sum of array.

🚀 5. Bonus Android Concepts

Thread-safe Singleton?
Use synchronized or Kotlin object keyword (thread-safe by default).
Observer pattern?
Used in LiveData → UI observes data changes automatically.
Why Coroutines?
Lightweight async programming, avoids callback hell.
What is caching?
Storing data locally (Room/Memory cache) to reduce API calls.
