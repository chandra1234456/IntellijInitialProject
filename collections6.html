📖 1. Collections Basics

1 What are Kotlin collections? How are they different from Java?

Kotlin collections distinguish between mutable and immutable (read-only) interfaces at the language level. Java collections are all mutable by default. Kotlin provides: List, MutableList, Set, MutableSet, Map, MutableMap.

// Immutable (read-only)
val list = listOf(1, 2, 3)
// Mutable
val mutableList = mutableListOf(1, 2, 3)
mutableList.add(4)
2 What is the difference between List and Array in Kotlin?

Array has fixed size, mutable elements, and is compiled to JVM arrays. List (immutable) has fixed size but supports more operations; MutableList can change size. Prefer List for type safety and functional operations.

val array = arrayOf(1, 2, 3)  // fixed size
val list = listOf(1, 2, 3)    // immutable
val mutableList = mutableListOf(1, 2, 3)  // dynamic size
3 Why prefer immutable collections in Android development?

Immutable collections are thread-safe, prevent accidental modification, and make code more predictable. In Android with MVVM, exposing immutable lists from ViewModels ensures UI stability and reduces bugs.

4 What is the difference between listOf() and emptyList()?

listOf() creates an empty read-only list, emptyList() is a specialized function returning a singleton empty list (more memory efficient). For mutable: mutableListOf().

🔢 2. Collection Types Deep Dive

5 Difference between List, Set, and Map?

List: Ordered, allows duplicates, index-based access.
Set: Unordered, unique elements, no duplicates.
Map: Key-value pairs, unique keys.

val list = listOf(1, 2, 2, 3)  // [1,2,2,3]
val set = setOf(1, 2, 2, 3)    // [1,2,3]
val map = mapOf(1 to "A", 2 to "B")
6 What is ArrayList vs mutableListOf()?

mutableListOf() returns an ArrayList by default on JVM. They are equivalent. arrayListOf() explicitly creates ArrayList. For Android, both work similarly; use mutableListOf() for clarity.

7 What is LinkedHashMap and when to use it?

LinkedHashMap maintains insertion order. In Kotlin, mutableMapOf() returns LinkedHashMap by default. Use when order matters for iteration.

val map = mutableMapOf("c" to 3, "a" to 1, "b" to 2)
// Iteration preserves insertion order: c, a, b
8 What are Sequence vs Iterable? Performance implications?

Sequence performs lazy evaluation (element-by-element), while Iterable operations are eager (create intermediate collections). Use Sequence for large chains of operations to avoid intermediate lists. In Android, use Sequence for large data processing.

val seq = (1..1_000_000).asSequence()
    .filter { it % 2 == 0 }
    .map { it * 2 }
    .take(10)
    .toList()  // Only processes 20 elements, not all 1M

⚙️ 3. Common Collection Operations

9 What is the difference between filter and map?

filter selects elements based on predicate, map transforms each element. Often chained together.

val numbers = listOf(1, 2, 3, 4, 5)
val evenSquares = numbers.filter { it % 2 == 0 }.map { it * it }  // [4, 16]
10 Explain flatMap and when to use it?

flatMap transforms each element into a collection and flattens the result. Perfect for nested lists or one-to-many transformations.

val list = listOf(1, 2, 3)
val result = list.flatMap { listOf(it, it * 10) }  // [1,10,2,20,3,30]
11 What is groupBy? Give Android use case.

groupBy groups elements by a key selector, returning a Map. Use case: Grouping chat messages by date, or grouping list items by category for RecyclerView.

data class Transaction(val category: String, val amount: Double)
val transactions = listOf(Transaction("Food", 10.0), Transaction("Food", 20.0), Transaction("Transport", 5.0))
val byCategory = transactions.groupBy { it.category }  // {Food=[...], Transport=[...]}
12 Difference between reduce and fold?

Both accumulate values. fold takes an initial value, reduce uses the first element as initial. fold can return different type.

val numbers = listOf(1, 2, 3, 4)
val sum = numbers.reduce { acc, i -> acc + i }  // 10
val sumWithInitial = numbers.fold(10) { acc, i -> acc + i }  // 20

🔧 4. Advanced Functional APIs

13 What is the difference between any, all, and none?

any() returns true if any element matches predicate. all() returns true if all match. none() returns true if none match.

val nums = listOf(2, 4, 6)
nums.any { it > 5 }  // true
nums.all { it % 2 == 0 }  // true
nums.none { it < 0 }  // true
14 What is associateBy vs groupBy?

associateBy creates a Map using unique keys (last occurrence wins). groupBy creates a Map of lists (multiple values per key).

data class Person(val id: Int, val name: String)
val people = listOf(Person(1, "Alice"), Person(2, "Bob"), Person(1, "Charlie"))
val map = people.associateBy { it.id }  // {1=Person(1,Charlie), 2=Person(2,Bob)}
val grouped = people.groupBy { it.id }  // {1=[Person(1,Alice), Person(1,Charlie)], 2=[Person(2,Bob)]}
15 Explain take, drop, and slice.

take(n) takes first n elements, takeLast(n) takes last n, drop(n) skips first n, slice takes indices range.

val list = (1..10).toList()
list.take(3)  // [1,2,3]
list.drop(7)  // [8,9,10]
list.slice(2..5)  // [3,4,5,6]
16 What is distinct and distinctBy?

distinct() returns list with unique elements. distinctBy returns unique elements based on a selector function.

val items = listOf("apple", "banana", "apricot", "blueberry")
items.distinctBy { it.first() }  // ["apple", "banana"] - first letters: a, b

📱 5. Android Specific Collection Questions

17 How to handle large lists in RecyclerView efficiently?

Use ListAdapter with DiffUtil for efficient updates. Use Sequence for processing large datasets before display. Consider pagination with Paging 3 library.

class MyAdapter : ListAdapter<Item, MyViewHolder>(DiffCallback()) {
    override fun submitList(list: List<Item>?) {
        // Efficiently updates only changed items
        super.submitList(list?.toList()) // defensive copy
    }
}
18 What is the issue with sharing mutable collections between ViewModel and Fragment?

Fragments might modify the collection causing inconsistent UI state. Always expose immutable collections (StateFlow<List<T>>). Use .toList() defensive copy when needed.

private val _items = MutableStateFlow<List<String>>(emptyList())
val items: StateFlow<List<String>> = _items  // read-only
19 How to sort a list of custom objects in Android?

Use sortedBy, sortedWith with Comparator, or implement Comparable interface.

data class Product(val name: String, val price: Double)
val products = listOf(Product("A", 100.0), Product("B", 50.0))
val sorted = products.sortedBy { it.price }
val withComparator = products.sortedWith(compareBy { it.name })

💪 6. Important Coding Challenges

C1 Find the first non-repeating character in a StringEasy
fun firstNonRepeatingChar(str: String): Char? {
    val freq = str.groupingBy { it }.eachCount()
    return str.firstOrNull { freq[it] == 1 }
}
// Input: "swiss" → Output: 'w'
C2 Merge two sorted lists into one sorted listEasy
fun mergeSorted(list1: List<Int>, list2: List<Int>): List<Int> {
    var i = 0; var j = 0
    val result = mutableListOf<Int>()
    while (i < list1.size && j < list2.size) {
        if (list1[i] < list2[j]) result.add(list1[i++])
        else result.add(list2[j++])
    }
    result.addAll(list1.drop(i))
    result.addAll(list2.drop(j))
    return result
}
C3 Group anagrams together from list of stringsMedium
fun groupAnagrams(words: List<String>): List<List<String>> {
    return words.groupBy { it.toCharArray().sorted().joinToString("") }.values.toList()
}
// Input: ["eat","tea","tan","ate","nat","bat"]
// Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
C4 Find the most frequent element in a listEasy
fun mostFrequent(list: List<Int>): Int? {
    return list.groupingBy { it }.eachCount().maxByOrNull { it.value }?.key
}
C5 Remove duplicates from list while preserving orderEasy
fun removeDuplicatesPreserveOrder(list: List<Int>): List<Int> {
    return list.distinct()
}
// Or manually: list.filter { set.add(it) } with LinkedHashSet
C6 Find pairs that sum to target valueMedium
fun findPairs(list: List<Int>, target: Int): List<Pair<Int, Int>> {
    val seen = mutableSetOf<Int>()
    val result = mutableListOf<Pair<Int, Int>>()
    for (num in list) {
        val complement = target - num
        if (complement in seen) {
            result.add(complement to num)
        }
        seen.add(num)
    }
    return result
}
C7 Flatten nested lists of any depthMedium
fun flatten(list: List<Any>): List<Any> = list.flatMap {
    if (it is List<*>) flatten(it) else listOf(it)
}
// Input: [1, [2, [3, 4]], 5] → Output: [1,2,3,4,5]
C8 Implement a frequency counter using foldEasy
fun charFrequency(str: String): Map<Char, Int> {
    return str.fold(mutableMapOf()) { map, char ->
        map[char] = map.getOrDefault(char, 0) + 1
        map
    }
}
C9 Chunk a list into sublists of given sizeEasy
fun <T> List<T>.chunk(size: Int): List<List<T>> {
    return (0 until this.size step size).map { i ->
        this.subList(i, minOf(i + size, this.size))
    }
}
// Input: [1,2,3,4,5], chunk 2 → [[1,2],[3,4],[5]]
C10 Intersection of two lists with duplicates preservedMedium
fun intersect(list1: List<Int>, list2: List<Int>): List<Int> {
    val map = list2.groupingBy { it }.eachCount().toMutableMap()
    return list1.filter {
        map[it]?.let { count ->
            map[it] = count - 1
            true
        } ?: false
    }
}

🚀 7. Advanced Topics

20 What are buildList, buildMap, buildSet? When to use?

These builder functions create immutable collections efficiently without intermediate mutable state. Perfect for complex construction logic.

val list = buildList {
    add(1)
    addAll(listOf(2, 3))
    if (condition) add(4)
}  // Returns immutable List
21 Performance comparison: List vs Sequence for large data processing in Android

For chains of operations (filter.map.filter), Sequence avoids creating intermediate lists. Use Sequence for large datasets (1000+ items). For small datasets, List is fine. In Android Room database queries, use Flow with Sequence for large result sets.

22 What are transforms like zip and unzip?

zip combines two lists into pairs. unzip splits list of pairs into two lists.

val names = listOf("Alice", "Bob")
val ages = listOf(25, 30)
val zipped = names.zip(ages)  // [(Alice,25), (Bob,30)]
val (unzippedNames, unzippedAges) = zipped.unzip()
23 What is the difference between sorted, sortedBy, and sortedWith?

sorted() uses natural order. sortedBy { selector } sorts by selected value. sortedWith(Comparator) uses custom comparator.

data class Person(val name: String, val age: Int)
val people = listOf(Person("Bob", 30), Person("Alice", 25))
people.sortedBy { it.age }  // Alice then Bob
people.sortedWith(compareBy { it.name })  // Alice then Bob by name
24 How to convert List to Map and handle duplicate keys?

Use associateBy for unique keys, groupBy for multiple values, or associateBy with value selector for handling duplicates.

val items = listOf("a", "b", "a")
items.associateWith { it.length }  // {a=1, b=1} - last a wins
items.groupBy { it }  // {a=[a,a], b=[b]}
