Kotlin Interview Questions & Answers

Null Safety

Null Safety Questions

Q1: What is Null Safety in Kotlin?
Kotlin provides built-in null safety to avoid NullPointerException. Variables cannot hold null values unless declared with ?.
var name: String = "Kotlin" // name = null ❌ var city: String? = null ✅
Q2: What does ?.let do?
Executes the block only if the variable is not null.
val name: String? = "Kotlin" name?.let { println(it.length) }
Q3: What is Elvis Operator ?: ?
Provides a default value if the expression is null.
val len = name?.length ?: 0
Q4: What is !! operator?
Converts nullable type to non-null type forcefully. May throw NullPointerException.
val length = name!!.length
Q5: Difference between requireNotNull() and !! ?
requireNotNull() throws IllegalArgumentException with custom message, while !! throws NullPointerException.
requireNotNull(name) { "Name cannot be null" }
Data Classes

Data Class Questions

Q6: What is a Data Class in Kotlin?
Data classes are used to store data. Kotlin automatically generates equals(), hashCode(), toString(), copy().
data class User( val name: String, val age: Int )
Q7: What is copy() function?
Creates a new object by copying an existing object.
val u1 = User("Raj", 22) val u2 = u1.copy(age = 25)
Q8: What is componentN()?
Used in destructuring declarations.
val (name, age) = user
Sealed & Enum

Sealed vs Enum vs Interface

Q9: Difference between Enum and Sealed class?
Enum is used for fixed constants. Sealed class is used for restricted class hierarchy.
sealed class Result class Success : Result() class Error : Result()
Q10: What is Interface in Kotlin?
Interface defines behavior contracts. It can contain abstract and default methods.
interface Engine { fun start() }
Extension Functions

Extension Function Questions

Q11: What are Extension Functions?
Extension functions allow adding new functions to existing classes without modifying them.
fun String.greet() { println("Hello $this") }
Q12: Can Extension Functions access private members?
No. They cannot access private or protected members.
Inline & Reified

Inline Function Questions

Q13: What is Inline Function?
Compiler copies the function body at call site to reduce overhead.
inline fun greet(action: () -> Unit) { action() }
Q14: What is Reified keyword?
Reified allows checking generic type at runtime.
inline fun <reified T> check(value: Any) { if(value is T) { println("Matched") } }
Q15: What is noinline?
Prevents lambda from being inlined.
Delegation

Delegation Questions

Q16: What is by lazy?
Initializes value only when used first time.
val data by lazy { "Loaded" }
Q17: What is observable delegate?
Detects value changes automatically.
var name by Delegates.observable("A") { _, old, new -> println("$old -> $new") }
Object & Companion

Object Questions

Q18: What is Object Declaration?
Used to create Singleton objects.
object Database { fun connect() { println("Connected") } }
Q19: What is Companion Object?
Companion object provides static-like behavior.
class MyClass { companion object { fun create(): MyClass { return MyClass() } } }
Coroutines

Coroutine Questions

Q20: What are Coroutines?
Coroutines are lightweight threads used for asynchronous programming.
GlobalScope.launch { delay(1000) println("Coroutine") }
Q21: What is suspend function?
Suspend functions can pause and resume without blocking thread.
suspend fun fetchData() { delay(1000) }
