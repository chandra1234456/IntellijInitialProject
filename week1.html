Kotlin Interview Questions & Answers

Null Safety

Q1: What does ?.let do?

Executes block only if value is non-null.

val name: String? = "Kotlin" name?.let { println(it.length) }
Q2: Elvis operator ?: ?
val len = name?.length ?: 0
Q3: What is !! ?

Forces non-null, may throw NullPointerException.

Q4: requireNotNull vs !!
requireNotNull(name) { "Cannot be null" }

Data Classes

Q5: copy()?
val u2 = u1.copy(age = 25)
Q6: equals/hashCode?

Based only on constructor properties.

Q7: componentN()?
val (name, age) = user

Sealed vs Enum vs Interface

Enum: Fixed constants

Sealed: Restricted class hierarchy

Interface: Flexible contracts

Extension Functions

Q8: How compiled?

Compiled as static functions.

Q9: Access private members?

No.

Inline & Reified

Q10: Inline function?

Copies function body at call site.

Q11: Reified?
inline fun check(value: Any) { if (value is T) println("Yes") }
Q12: noinline?

Prevents lambda from being inlined.

Delegation

Q13: by lazy
val value by lazy { 10 }
Q14: observable
var name by Delegates.observable("A") { _, old, new -> println("$old -> $new") }
