🧠 OOPs + SOLID Coding Interview Problems (Android)

🧠 1. OOPs Coding Problems

1. Bank System Design
Create BankAccount, SavingsAccount, CurrentAccount with deposit & withdraw methods. 
open class BankAccount(protected var balance: Double) {
    open fun deposit(amount: Double) {
        balance += amount
    }

    open fun withdraw(amount: Double) {
        if (balance >= amount) balance -= amount
    }
}
2. Shape Area System
Use interface Shape with Circle, Rectangle implementation. 
interface Shape {
    fun area(): Double
}

class Circle(private val r: Double) : Shape {
    override fun area() = Math.PI * r * r
}
3. Vehicle System
Vehicle → Car, Bike, Truck using inheritance.
4. Employee System
Employee → Developer, Manager using polymorphism.
5. Notification System
Send notifications via Email, SMS, Push using interface.

🏗️ 2. SOLID Coding Problems

1. Fix God Class (SRP Violation)
Split DB, UI, Network into separate classes.
2. Payment System (OCP Violation Fix)
Bad Code: 
class Payment {
    fun pay(type: String) {
        if (type == "card") {}
        if (type == "upi") {}
    }
}
Fix using interfaces:
interface PaymentMethod {
    fun pay()
}

class UpiPayment : PaymentMethod {
    override fun pay() {}
}
3. Liskov Substitution Problem
Bird system fix (Ostrich cannot fly problem). 
interface Bird
interface Flyable {
    fun fly()
}
4. Interface Segregation Fix
Split large interface into smaller ones. 
interface Workable {
    fun work()
}

interface Eatable {
    fun eat()
}
5. Dependency Inversion (Android Important)
Depend on abstraction, not concrete class. 
class ViewModel(private val repo: Repository)
