Top 50 Android Interview Questions & Answers

Kotlin & Core Java

1. What are the key differences between Kotlin and Java?
Kotlin is concise, null-safe, and supports coroutines. Java is more verbose and lacks built-in null safety.
2. Explain val vs var.
val is immutable (read-only), var is mutable.
3. What are coroutines?
Lightweight threads used for asynchronous programming.
4. suspend vs normal function?
Suspend functions can pause without blocking threads.
5. What is Flow?
A stream of asynchronous data that emits multiple values over time.
6. Null safety?
Kotlin prevents null pointer exceptions using nullable and non-null types.

Jetpack Compose

7. What is Jetpack Compose?
Modern declarative UI toolkit for Android.
8. What is recomposition?
UI updates when state changes.
9. remember vs mutableStateOf?
remember stores state, mutableStateOf makes it observable.
10. LazyColumn?
Efficient list that loads items lazily.
11. State hoisting?
Moving state to a higher-level component.
12. Side effects?
Operations outside UI like API calls using LaunchedEffect.

MVVM & Clean Architecture

13. What is MVVM?
Separates UI, logic, and data using ViewModel.
14. Role of ViewModel?
Holds UI data and survives configuration changes.
15. Clean Architecture?
Separates app into layers: UI, Domain, Data.
16. Use case?
Represents a single business logic operation.
17. Repository pattern?
Abstracts data sources (API, DB).
18. MVVM vs MVP?
MVVM uses data binding; MVP uses presenter.

Dependency Injection

19. What is DI?
Providing dependencies instead of creating them.
20. Why Hilt?
Simplifies dependency injection in Android.
21. Dagger vs Hilt?
Hilt is built on Dagger but easier to use.
22. Scopes?
Define lifecycle of dependencies.
23. Singleton?
Single instance throughout app lifecycle.
24. @Inject?
Used to request dependency injection.

25. What is Room?

26. Entity?

27. DAO?

28. Migration?
Handles schema updates without data loss.
29. Room vs SQLite?
Room is easier and safer.
30. Flow with Room?
Observe real-time database changes.

IoT / BLE

42. What is BLE?
Low-energy Bluetooth communication.
43. Bluetooth vs BLE?
BLE uses less power.
44. BLE lifecycle?
Scan → Connect → Discover → Communicate.
45. GATT?
Defines BLE data structure.
46. Scan devices?
Using BluetoothLeScanner.
47. Handle disconnect?
Retry or notify user.
48. Permissions?
Bluetooth + Location (Android 12+ specific permissions).
49. Battery optimization?
Reduce scan frequency.
50. BLE use case?
Fitness trackers, smart devices.
