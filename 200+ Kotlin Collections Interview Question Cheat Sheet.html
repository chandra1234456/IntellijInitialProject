List (1–40)

1. What is List in Kotlin?
Ordered collection of elements.
2. Mutable vs Immutable List?
MutableList allows modifications, List does not.
3. Is List ordered?
Yes, maintains insertion order.
4. Can List have duplicates?
Yes.
5. How to create empty list?
emptyList()
6. What is ArrayList?
Resizable list implementation.
7. Difference between List and Array?
List is dynamic, Array is fixed size.
8. How to access element in List?
Using index [i].
9. What is first()?
Returns first element.
10. What is last()?
Returns last element.
11. What is size property?
Returns number of elements.
12. What is contains()?
Checks element presence.
13. What is indexOf()?
Returns index of element.
14. What is subList()?
Returns portion of list.
15. What is drop()?
Removes first N elements.
16. What is take()?
Takes first N elements.
17. What is reversed()?
Reverses list.
18. What is sorted()?
Sorts list ascending.
19. What is sortedDescending()?
Sorts list descending.
20. What is distinct()?
Removes duplicates.
